# Robô de Ofertas do Mercado Livre (Gerador de PDF)

Este é um script em Python que eu criei para treinar automação e web scraping. Fiz ele inteiro pelo celular usando o aplicativo Pydroid 3.

## 🛠️ O que o código faz:
1. Entra na página de ofertas do Mercado Livre de forma automática.
2. Pega o título, o preço e o link dos produtos.
3. Cria um arquivo PDF estilizado com os dados encontrados.
4. Adiciona links clicáveis dentro do próprio PDF.

## 📱 Feito no Celular
Criei esse projeto para provar que dá para aprender lógica de programação de verdade e manipulação de arquivos mesmo sem ter um computador ainda. 

O código usa as bibliotecas `requests`, `bs4` (BeautifulSoup) e `reportlab`.
